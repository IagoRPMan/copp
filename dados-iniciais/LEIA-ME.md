# Dados iniciais

`npm run carga` lê `condominios.csv` desta pasta: os condomínios, o gerente de cada um e o supervisor dos gerentes.

O arquivo de verdade tem nomes e matrículas de pessoas e **não entra no repositório** (o `.gitignore` ignora todo `.csv` daqui). Para montar o seu, baixe o modelo em Cadastros → Condomínios → "Baixar modelo", ou use estas colunas, separadas por ponto e vírgula:

```
codigo;nome;conta_papercut;login_responsavel;nome_responsavel;matricula_responsavel;departamento;login_superior;nome_superior
```
